# TypeLaw

> TypeLaw is an AI-powered legal document automation platform that formats and prepares court-compliant briefs for attorneys, paralegals, and law firms. Lawyers upload a draft brief and pick the court; TypeLaw produces a compliant PDF with tables of contents, tables of authorities, hyperlinked citations, cover pages, and certificates, with a human expert reviewing every document before delivery.

TypeLaw is a Bloomberg Beta portfolio company. It does not currently publish a public developer API, developer documentation, SDKs, or an API status page. The product is delivered through its web application at app.typelaw.com. This file was generated by the API Evangelist enrichment pipeline from the company's public website.
